# Capsule Engine

Capsule is a deterministic, code-first 2D game engine for C#. Scenes are code, maps are data, and gameplay is kept separate from the graphics host so it can run in headless tests.

| Package | Purpose |
| --- | --- |
| `JAG.Capsule` | Substrate-free gameplay APIs: simulation, input, rendering contracts, maps, and scenes. |
| `JAG.Capsule.Runtime` | Window, device, clock, input sampling, and renderer. |
| `JAG.Capsule.Build` | Analyzers, generators, asset hooks, and map import. |

Start with the [repository quickstart](https://github.com/just-awesome-games/capsule-engine#quick-start) and [game setup](https://github.com/just-awesome-games/capsule-engine/blob/main/docs/consuming-capsule.md).
